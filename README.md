# Zeravia Final Capstone - Machine Learning Projects

This repository contains the three machine learning projects I completed as part of my Zeravia learning journey.

## Projects

### 1. Customer Churn Prediction
A machine learning project to predict the probability of customer churn using customer service, contract, tenure, and billing-related features.

**Models used:**
- Logistic Regression
- Random Forest
- XGBoost

**Tools:** Python, Pandas, NumPy, Scikit-learn, XGBoost, Streamlit

### 2. Predictive Maintenance and Early Failure Warning
A machine learning project that uses machine sensor data to identify machines at higher risk of failure and generate early warning levels.

**Models used:**
- Logistic Regression
- Random Forest
- Gradient Boosting

**Tools:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Streamlit

### 3. Personalized Product Recommendation
A recommendation system built using user-item interactions to generate personalized product recommendations.

**Methods used:**
- Popularity-based recommendation
- Collaborative filtering
- Content-based recommendation
- Hybrid recommendation

**Tools:** Python, Pandas, NumPy, Scikit-learn, TF-IDF, Truncated SVD, Streamlit

## Repository Contents

The repository includes the main Python scripts and Streamlit application files for all three projects.

## Note

The original datasets and large model files are not included in this repository because of their file size. The projects were developed and tested locally using the respective datasets.
